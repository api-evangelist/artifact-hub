# Artifact Hub

> Artifact Hub is a CNCF web application for finding, installing and publishing cloud-native
> packages. It indexes 27+ artifact kinds — Helm charts and plugins, OLM operators, OPA and
> Kyverno and Kubewarden policies, Falco rules, Tekton tasks/pipelines/stepactions, KEDA
> scalers, CoreDNS plugins, Krew kubectl plugins, Backstage plugins, Argo templates, KCL
> modules, Meshery designs, Radius recipes, Tinkerbell actions, container images and more —
> and exposes all of it through a public REST API at https://artifacthub.io/api/v1.
> The project is Apache-2.0 licensed and can be self-hosted from its official Helm chart.

Generated by API Evangelist on 2026-09-04 from this repository's apis.yml and artifacts.
Artifact Hub does not publish an llms.txt of its own: https://artifacthub.io/llms.txt
returns HTTP 200 with the site's 6,767-byte SPA shell (text/html), not a text document.

## API basics

- Base URL: https://artifacthub.io/api/v1
- Contract: OpenAPI 3.0.3, version 1.23.0, 111 paths / 129 operations
  (https://github.com/artifacthub/hub/blob/master/docs/api/openapi.yaml)
- Interactive reference: https://artifacthub.io/docs/api/
- Auth: two API-key headers sent TOGETHER — X-API-KEY-ID and X-API-KEY-SECRET.
  Read endpoints (search, package details, values, templates, security reports, stats,
  integration dumps) need no credentials at all.
- Pagination: `limit` (default 20, maximum 60) and `offset` query parameters; the response
  carries a `Pagination-Total-Count` header with the full result count.
- Errors: JSON body `{"message": "..."}`. Not RFC 9457 problem+json.
- Rate limits: enforced (429 is documented on all 129 operations) but the numbers are
  deliberately undocumented — see https://artifacthub.io/docs/topics/faq/

## APIs in this record

- Artifact Hub Packages API — search and retrieve packages of every supported kind (75 ops)
- Artifact Hub Organizations API — organizations, members, authorization policies (12 ops)
- Artifact Hub Repositories API — register, update, transfer and claim repositories (11 ops)
- Artifact Hub Webhooks API — user and organization webhooks, plus a test trigger (11 ops)
- Artifact Hub Users API — registration, profile, password and email verification (8 ops)
- Artifact Hub Subscriptions API — package subscriptions and opt-out entries (7 ops)
- Artifact Hub Integrations API — Harbor replication, Helm exporter and Nova dumps (3 ops)
- Artifact Hub Stats API — site-wide package and release counts (1 op)
- Artifact Hub Availability checks API — check whether a name is free (1 op)

## Useful entry points for an agent

- Search: GET /api/v1/packages/search?ts_query_web=<terms>&limit=20&facets=false
- Chart values: GET /api/v1/packages/{packageID}/{version}/values
- Values JSON Schema: GET /api/v1/packages/{packageID}/{version}/values-schema
- Rendered templates: GET /api/v1/packages/{packageID}/{version}/templates
- Security report (Trivy JSON): GET /api/v1/packages/{packageID}/{version}/security-report
- Bulk, rate-limit-friendly dump of every listed chart:
  GET /api/v1/harbor-replication  (the FAQ recommends this over paging search)
